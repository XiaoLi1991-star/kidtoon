# 动画片小助手

整理日期：2026-06-03

> 这是给家长用的动画片分集检索目录：先能快速回答“哪一季在哪个平台看”“腾讯第几集叫什么”“某个角色/主题在哪些集出现”。所有回答优先从本目录的 Markdown 文件里取；如果是推断或待核验，要明确标出来。

## 目录规则

每部动画单独一个目录，发布到 KidToon skill 的运行时资料采用 3 个查询文件：

| 文件 | 用途 |
|---|---|
| `01-分集平台清单.md` | 主入口：按季列出平台、集标题、简介/关键词、备注。 |
| `02-分集人物索引.md` | 查角色/萌可/狗狗/主要人物在哪些集出现。 |
| `03-平台标题映射-腾讯视频.md` | 腾讯视频专用映射：腾讯第几集、腾讯标题、播放链接。 |

`research-YYYYMMDD.md` 属于开发/调研留档，保留在原始项目中，不默认打包进 skill。

## 使用口径

- 回答“在哪个平台看”：优先看对应动画的 `01-分集平台清单.md`。
- 回答“腾讯上第几集”：优先看 `03-平台标题映射-腾讯视频.md`，因为平台集号可能和通用分集表不同。
- 回答“某个角色在哪些集”：优先看 `02-分集人物索引.md`，并说明是“已核验出场”还是“按标题提取/推断”。
- B站、UP 主合集、片段、预告默认不作为正式平台，除非能确认官方正版完整专辑。
- 新增动画并发布到 skill 时，直接新建同名目录并补齐这 3 个查询文件；调研过程可另存在原始项目。
